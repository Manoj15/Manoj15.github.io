# Mind Map Studio

A static mind map site for GitHub Pages. Each map is a Markdown file in
[`maps/`](maps/); the site renders it as an interactive mind map with
[markmap](https://markmap.js.org/).

Live site: <https://manoj15.github.io/mindmaps/>

## What you can do on the site

| Area | Tools |
| --- | --- |
| Gallery | Search, tag filters, local drafts, open a `.md` file, copy a ready-made Claude prompt |
| Explore | Zoom, fit, expand all, collapse, show N levels, find node (with next/previous), fullscreen, light/dark |
| Style | Node wrap width, horizontal and vertical spacing, branch colour freezing, click-folds-whole-branch |
| Edit | Live side-by-side Markdown editor, autosaved drafts, Tab/Shift+Tab indent, list continuation, Tidy, front matter template |
| Publish | **Save to GitHub** opens a pre-filled commit page; or commit the file any other way |
| Share | Share link with the whole map in the URL; export SVG, PNG, offline interactive HTML, Markdown |

Press `?` on the site for keyboard shortcuts.

## Adding a map (for people and for Claude)

1. Create `mindmaps/maps/<kebab-case-name>.md`. The file name is the URL slug:
   `maps/ab-testing.md` → `#/map/ab-testing`.
2. Start with front matter:

   ```markdown
   ---
   title: A/B Testing
   description: One sentence shown on the gallery card.
   tags: [statistics, experimentation]
   markmap:
     colorFreezeLevel: 2     # one colour per main branch
     initialExpandLevel: 2   # levels open on first load (-1 = all)
     maxWidth: 320           # wrap nodes wider than this many px (0 = never)
   ---
   ```

3. Write the tree:
   - `# Title`: exactly one, the root.
   - `## Branch`: main branches (aim for 5 to 9).
   - `### Sub-branch`: optional.
   - `- bullet` lists under any heading, nested with 2 spaces, for detail.
   - Keep each node to a short phrase. Split long ideas into children.
   - Allowed inline: `**bold**`, `*italic*`, `` `code` ``, `[link](url)`,
     `==highlight==`, `$math$` (KaTeX), `- [ ]` checkboxes, and fenced code
     blocks indented under a bullet.
4. Rebuild the index so the gallery lists the map:

   ```bash
   python3 mindmaps/build_manifest.py
   ```

5. Commit and push to `master`. GitHub Pages redeploys the site in about a
   minute. If you forget step 4, the `Rebuild mind map index` workflow in
   `.github/workflows/mindmaps-index.yml` does it for you, and the live site
   also finds new map files through the GitHub API in the meantime.

## Running locally

```bash
cd mindmaps && python3 -m http.server 8000
```

Then open <http://localhost:8000>. (Opening `index.html` directly from disk
does not work, because the page fetches the map files.)

## Hosting

The site lives in the `mindmaps/` folder of the `Manoj15.github.io` user site,
which GitHub Pages serves from the `master` branch. The `.nojekyll` file at the
repo root stops Jekyll from converting the map `.md` files into HTML.

## Files

```
mindmaps/
  index.html          app shell
  config.js           GitHub owner/repo/branch for "Save to GitHub" and map discovery
  assets/app.js       app logic (gallery, viewer, editor, exports)
  assets/app.css      styles, light and dark
  maps/*.md           the maps
  maps/index.json     generated by build_manifest.py
  vendor/             pinned copies of d3 7.9.0, markmap 0.18.12, lz-string 1.5.0
  build_manifest.py   builds maps/index.json
```

Math and code highlighting load KaTeX / highlight.js from jsDelivr on first use.
